# Deliberate exceptions for scripts/check_doc_links.sh.
#
# Format, one per line:   <cited path> :: <citing-file glob> :: <why>
#
# The referrer glob is not optional and not decorative: a prose paragraph that
# explains why a document was retired legitimately names it, but a fresh source
# comment citing the same dead path is exactly the bug this check exists to
# catch (ARCHITECTURE_OVERHAUL.md §5 C-8). Scoping each exception to the file
# that earns it keeps the second case failing.
#
# An entry whose file now exists, or that nothing cites any more, FAILS the
# check. Delete the line -- that is the intended maintenance.

# --- Retired planning docs, named by the documents that record their removal.

docs/planning/Errors.md :: docs/planning/ARCHITECTURE_OVERHAUL.md :: §5 C-8 uses this exact path as the worked example of a dangling reference -- the citation is the point.
docs/planning/COMPILER_MODULE_BREAKDOWN.md :: docs/architecture/compiler_pipeline.md :: records that the 2026-08 module-split plan was retired once the split landed, and that this document replaced it.
docs/planning/FINAL_SPRINT.md :: docs/planning/ROADMAP_v1.0.0_COMPLETE.md :: §3's note explaining that the final-sprint checklist was removed once everything it tracked landed.
docs/detailed/modules_and_stdlib.md :: docs/architecture/modules_and_scope_resolution.md :: §0 records that this stale doc was removed rather than corrected, and that this document replaced it.
