Exception System Removal (try/onError/raise)

1. Changes Made:
- Completely removed `TOK_TRY`, `TOK_ONERROR`, and `TOK_RAISE` from `enum Token` in `include/Lexer.h`.
- Deleted all exceptions-related AST node definitions (`TryExprAST`, `RaiseExprAST`, and `OnErrorExprAST`) from `include/AST.h`.
- Removed parser functions `ParseTryExpr` and `ParseRaiseExpr`, and deleted `case TOK_TRY:` parsing logic from `ParsePrimaryBase` in `src/Parser.cpp`.
- Deleted exception checking, symbol resolution, and type checking visitor overrides from `src/Resolver.cpp` and `src/TypeChecker.cpp`.
- Removed codegen methods for `TryExprAST`, `OnErrorExprAST`, and `RaiseExprAST` from `src/Codegen.cpp`.
- Replaced the modulo-by-zero and divide-by-zero runtime error exception paths in `BinaryExprAST::codegen()` with direct calls to the global `fail` intrinsic.
- Cleaned up stubs in `tests/builtins_stubs.cpp` and `tests/codegen_stubs.cpp`.
- Updated all standard library `.tr` files under `lib/std/` to use the new `fn name(param: type): returnType` signature syntax, and replaced any `raise` statements with the global `fail()` intrinsic call.

2. Why the Change was Made:
- Error handling in Turflang is standardized to return values (Result-style structs) for recoverable errors and the `fail()` intrinsic for unrecoverable panics.
- The `try/onError/raise` system introduced compiler complexity (including LLVM codegen for exception stacks, setjmp/longjmp handling, and heap allocations to survive stack unwinding). Removing it simplifies the compiler architecture.

3. How it Helps/Changed:
- Simpler, cleaner AST structure and fewer visitor methods.
- More lightweight codegen target (no need to construct or maintain exception stack structures or generate longjmp jumps).
- Cleaner, more predictable error paths (unrecoverable issues fail immediately with descriptive messages).

4. Reference & Usage Examples (Source of Truth):

a) Division by Zero
Expected behavior when dividing/modulo by zero:
```turflang
fn main(): int {
    mutable x: int = 10 / 0; // Runtime failure: prints "Division by zero" and aborts
    return 0;
}
```

b) Fail Intrinsic
Unrecoverable panic using `fail()`:
```turflang
fn main(): int {
    fail("Something went wrong!"); // Aborts execution with the given message to stderr
    return 0;
}
```
