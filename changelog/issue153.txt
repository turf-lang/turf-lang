Casting Syntax Overhaul (x to type)

1. Changes Made:
- Added `TOK_TO = -68` to the `Token` enum in `include/Lexer.h`.
- Registered the `"to"` keyword in the `Keywords` map inside `src/Lexer.cpp`.
- Set the precedence of `TOK_TO` to `5` in `InitializePrecedence()` inside `src/Parser.cpp`, making it lower than `||` (15) but higher than assignment (10).
- Handled the `TOK_TO` operator inside `ParseBinOpRHS()` in `src/Parser.cpp` to directly consume the target type using `ParseType()`, construct a `CastExprAST` node, and continue precedence climbing.
- Deleted `ParseCastExpr()` declaration and definition from `src/Parser.cpp` since the C-style `type(x)` cast syntax is replaced.
- Patched `TypeChecker::inferRelationalType` in `src/TypeChecker.cpp` to recognize `TOK_EQ` (`-9`) and `TOK_NEQ` (`-10`) as relational equality operators.
- Created `test_cast.tr` to verify basic casts (`n to int`, `i to string`), chained casting (`x to int to double`), and integration checks.

2. Why the Change was Made:
- The old C-style `type(x)` cast syntax (e.g. `int(x)`) required a `GlobalSymbolTable` lookup inside the parser to distinguish cast expressions from standard function calls.
- By introducing the `to` keyword (`x to type`), we decouple parsing from type symbol table lookups, resolving parser-level ambiguities and simplifying the parsing architecture.

3. How it Helps/Changed:
- Simpler and cleaner parser loop with no need for the `GlobalSymbolTable` lookups mid-parse.
- Provides a clear, readable syntax for type conversions that matches modern systems programming language styles.
- Avoids grammar ambiguities when parsing casts in complex expressions.

4. Reference & Usage Examples (Source of Truth):

a) Basic Casting
Converting a double to an integer, then to a string:
```turflang
fn main(): int {
    mutable n: double = 3.99;
    mutable i: int = n to int;       // i becomes 3
    mutable s: string = i to string; // s becomes "3"
    
    assert(i == 3);
    assert(s to int == 3);
    return 0;
}
```

b) Chained Casting
Multiple casts chained in a single expression:
```turflang
fn main(): int {
    mutable x: double = 3.99;
    mutable d: double = x to int to double; // parses as: (x to int) to double
    assert(d == 3.0);
    return 0;
}
```
