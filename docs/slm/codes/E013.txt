TURF E013 -- RETIRED (code after a terminator is now always E012):

STATUS:
  No longer raised. The number is kept so an old log that mentions it still resolves, and is
  never reused.

HISTORY:
  E013 used to be reported when a variable DECLARATION came after a `return`/`break`/`continue`
  in the same block, from a Codegen backstop. It was the same mistake as E012 under a second
  number, and the CFG pass always reported E012 first, so E013 was never seen in practice.
  Every statement in that position, declarations included, is now E012.

INCORRECT (reports E012):
    fn main(): int {
        return 0;
        mut x: int = 5;     // E012
    }

FIX:
  Delete the dead code or move it before the terminator.

SEE: E012 (statement after a terminator), E074 (unreachable block, a warning).
