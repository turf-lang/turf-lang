TURF E034 -- DUPLICATE STRUCT/ENUM/ERROR-TYPE NAME:

CAUSE:
  Two `struct`, `enum`, or `error` type declarations in the SAME file (or
  the same module) used the same name. A type belongs to its declaring
  module, so an imported module declaring a type with the same name as one
  of yours is NOT this error -- they are two separate types (if a bare use
  of the name becomes ambiguous, that is E085 instead). Distinct from
  DuplicateDeclarationError (E033), which is about a VARIABLE name reused
  in the same scope, not a type name.

CORRECT:
    struct Point { x: int, y: int }
    struct Point3D { x: int, y: int, z: int }   // different name, fine

INCORRECT:
    struct Point { x: int, y: int }
    struct Point { x: double, y: double }
    // ERROR: A struct named 'Point' is already declared.
    //   Note: first declared here (line 1, ...)

FIX:
  Rename one of the two conflicting declarations in that file.
