TURF E006 -- RETIRED (for-each over an unsized array parameter is legal now):

STATUS:
  No longer raised. The number is kept so an old log that mentions it still resolves, and is
  never reused.

HISTORY:
  E006 was reported for `for x in arr { ... }` when `arr` was an unsized array parameter
  (`arr: T[]`), because that parameter was a bare pointer with no length. Since issue #260 a
  `T[]` parameter is a slice -- a pointer to the caller's elements plus their count -- so
  for-each, `arr.length()` and bounds-checked `arr[i]` all work on it.

CORRECT USAGE (compiles):
    fn sum(arr: int[]): int {
        mut total: int = 0;
        for value in arr {
            total = total + value;
        }
        return total;
    }

SEE: E140 (a `T[]` written anywhere but a function parameter), E141 (an `immut` array passed
  to a `T[]` parameter that the function writes through), E005 (for-each over a non-array).
