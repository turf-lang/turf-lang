TURF E063 -- RETIRED (a bad argument to power() is now E056 or E025):

STATUS:
  No longer raised. `power` used to be a compiler built-in with its own error; it is now an
  ordinary standard-library function (`math::power`), so a bad argument is reported like any
  other call with wrong argument types. The number is kept so an old log that mentions it still
  resolves, and is never reused.

INCORRECT (reports E056 or E025):
    mut bad: int = math::power(true, 2);

VALID:
    math::power(int, int)       -> int
    math::power(int, double)    -> double
    math::power(double, int)    -> double
    math::power(double, double) -> double

SEE: E056 (wrong argument type to a function), E025 (no matching module overload).
