TURF E123 -- INVALID ARRAY SIZE:

CAUSE:
  An array's declared size (`int[N]`) is a count of slots and must be a positive whole
  number. Zero, negative and fractional sizes are rejected.

INCORRECT:
    mut empty: int[0];               // no slots can hold nothing
    mut negative: int[-3];
    mut half: int[2.5];

EMPTY LITERAL:
  An unsized declaration takes its size from a literal initializer (`mut nums: int[] = [1, 2,
  3];` is `int[3]`). An empty literal gives no size and is also E123:
    mut a: int[] = [];               // "An empty literal can't give 'a' a size"
  Fix: give the literal at least one element, or declare the size (`mut a: int[5];`).

CORRECT:
    mut numbers: int[5];             // five slots

FIX:
  Use a positive whole size. If the count is not known in advance, an array is the
  wrong tool: use `List<T>` (`import list;`), which grows.

NOTE: `int[0]` may additionally print a second error (a registered cascade); the size
  is the real mistake.

RELATED: E003 (array size mismatch), E002 (array index must be an integer).
