TURF E026 -- MODULE METHOD NOT FOUND:

CAUSE:
  A module-qualified call (`module::name(...)`) names a function that
  doesn't exist anywhere in that module at all -- distinct from E025
  (function exists, wrong argument types). Suggestions are sourced from
  that module's real function registry via the same trie every other
  "unknown name" diagnostic in this compiler uses.

EXAMPLE:
    io::pritn("hello");   // ERROR: no such function -- typo for printline

FIX:
  Check the spelling against the module's real exported function names
  (Turf will usually suggest the closest match itself), or check that the
  module you're importing actually defines what you're looking for --
  grep the module's own `.tr` file (e.g. `lib/std/io/io.tr`) for its `fn`
  declarations if you aren't sure.

WHAT THIS ERROR IS NOT:
  Not about the MODULE itself not existing (that's ModuleNotFoundError,
  E027) -- this fires only once the module was found successfully, and
  it's specifically the function name inside it that doesn't exist.
