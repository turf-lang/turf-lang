TURF E126 -- UNSUPPORTED OPERATION:

CAUSE:
  A shorthand form is not available where the longer form works. The message names the
  form and shows the long way.
    - `int32` is a storage type: arithmetic on it yields `int`, never `int32`, so
      `x += 1`, `x++` and `x--` on an `int32` are not supported;
    - compound assignment through a user-defined `operator[]` (`grid[i] += 1`);
    - indexing a value that cannot be indexed (`n[0]` on an `int`): only arrays, strings,
      pointers and types that define `operator[]` can use `[ ]`.

INCORRECT:
    mut x: int32 = 5 to int32;
    x += 1;
    grid[i] += 1;
    mut n: int = 3;
    n[0];

CORRECT:
    struct Grid { n: int }

    operator [](g: Grid, i: int): int {
        return g.n + i;
    }

    operator []=(g: Grid, i: int, v: int): void {
        g.n = v;
    }

    mut x: int32 = 5 to int32;
    mut grid: Grid = Grid::default();
    mut i: int = 0;
    x = (x + 1) to int32;             // arithmetic, then convert back
    grid[i] = grid[i] + 1;            // write the read and the write out

FIX:
  Expand the shorthand as shown.

RELATED: E124 (invalid comparison), E134 (conversion not allowed), E098 (write to a
  temporary).
