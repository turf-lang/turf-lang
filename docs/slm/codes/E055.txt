TURF E055 -- RETIRED (a bad argument to abs() is now E056 or E025):

STATUS:
  No longer raised. `abs` used to be a compiler built-in with its own error; it is now an
  ordinary standard-library function (`math::abs`), so a bad argument is reported like any other
  call with wrong argument types. The number is kept so an old log that mentions it still
  resolves, and is never reused.

INCORRECT (reports E056 or E025):
    mut bad: int = math::abs("negative five");

VALID:
    math::abs(int)    -> int
    math::abs(double) -> double

SEE: E056 (wrong argument type to a function), E025 (no matching module overload).
