TURF E004 -- ARRAY TYPE MISMATCH:

CAUSE:
  An array's initializer list contains a value whose type doesn't match
  the array's declared element type. Every value in `[v1, v2, ...]` must
  be the same type as the array itself (or a compatible numeric
  promotion, e.g. an int literal into a `double[]`).

CORRECT USAGE:
    immut primes: int[3] = [2, 3, 5];                 // all int
    immut vals: double[3] = [1.0, 2.0, 3.0];           // all double

INCORRECT:
    immut primes: int[3] = [2, 3, "five"];
    // ERROR: I cannot put a `string` in an array of `int`.

FIX:
  Decide which side is wrong. If the written element type is the mistake
  (every value is an `int` and the code uses them as numbers), change the
  declaration: `mut codes: int[3] = [10, 20, 30];`. If the values are, make
  each one the declared element type: convert it with `to` where a
  conversion exists (`x to char`), otherwise write a value of that type.
  Never mix types in one literal.
