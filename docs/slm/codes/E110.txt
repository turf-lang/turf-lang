TURF E110 -- SPECIFIC WORD OR SYMBOL EXPECTED:

CAUSE:
  The parser was inside a construct with a fixed shape and found something other than
  the next fixed piece; the message names the exact word/symbol wanted. Fixed shapes:
    for i in 0..10 { ... }               // `in` after the loop variable
    do { ... } while keepGoing;          // `while` after a do-block
    give a otherwise b                   // `otherwise` after `give`
    compare x { matches 1: ... }         // `matches` or `otherwise` inside compare
    value recover run { ... };           // `run`, `produce` or `as` after `recover`
    extern fn malloc(n: int): ptr;       // `fn` after `extern`
    export immut MAX: int = 3;           // `immut` after `export`
    machine Door { Open -> Closed }      // `->` between two states

FIX:
  Compare what was written with the shape above and add or fix the piece the message
  asks for. A lookalike (`then` instead of `{`, `:=` instead of `=`) is the thing to
  change: Turf has no aliases for them.

RELATED: E103 (unexpected token), E107 (missing brace), E113 (removed syntax).
