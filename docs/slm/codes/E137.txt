TURF E137 -- NOT A VALUE:

CAUSE:
  A function was named without calling it in a form that has no value. A function value is
  written by its BARE name (`twice`, after `import helper::twice;` for a module's function).
  A qualified name (`io::printline`, `Point::origin`) is only ever called, and so is an
  `@caller_location` function. A generic function is a value only where a function type is
  declared for it (`immut f: fn(int): int = id;`); `mut g = id;` gives it no type.

INCORRECT:
    import helper;
    mut f: fn(int): int = helper::twice;   // qualified name used as a value

CORRECT:
    fn twice(x: int): int {
        return x * 2;
    }

    fn main(): int {
        mut f: fn(int): int = twice;       // the bare name is a value
        return f(2) - 4;
    }

FIX:
  Import the function by name and use the bare name, or call it where its result is needed.
  A static method has no value form: wrap the call in a plain function and use that name.

RELATED: E135 (calling something that is not a function), E067 (using a void result).
