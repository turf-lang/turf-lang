TURF E012 -- STATEMENT AFTER TERMINATOR:

CAUSE:
  A statement appears immediately after a terminator (`return`, `break`,
  `continue`) in the SAME block, with nothing conditional separating them.
  Since the terminator unconditionally exits the block, every statement
  after it in that block is dead code -- guaranteed to never run.

CORRECT USAGE:
    fn abs(x: int): int {
        if x < 0 {
            return -x;
        }
        return x;
    }

INCORRECT:
    fn example(): int {
        return 5;
        io::printline("this never prints");
        // ERROR: this code comes after a return, so it's impossible to
        // reach it.
    }

WHAT THIS ERROR IS NOT:
  - Not the unreachable-BLOCK warning (E074), which flags a whole block
    that no path reaches (e.g. the code after `while true { return 1; }`)
    rather than a statement in the same block as its terminator.
  - A variable DECLARATION after a terminator is also E012. It used to be
    a separate code, E013, which is now retired.

FIX:
  Delete the dead statement(s), or move them BEFORE the terminator if they
  were meant to run first.
