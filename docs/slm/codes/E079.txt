TURF E079 -- GENERIC INSTANTIATION DEPTH EXCEEDED:

CAUSE:
  A generic function or method is compiled once per distinct type it is used with
  (`wrap<int>`, `wrap<&int>`, ...). This one keeps asking for a NEW type at every
  level of its own recursion, so the chain never reaches a copy that already
  exists and the compiler stops it at 64 levels (or 4096 instantiations in all).
  The usual shape is a recursive call whose argument is built AROUND the type
  parameter (`&x`, a `Box<T>`) instead of being a `T`:

    fn<T> wrap(x: &T): int {
        return wrap(&x);        // wrap<int> -> wrap<&int> -> wrap<&&int> -> ...
    }
    fn main(): int {
        mut v: int = 1;
        return wrap(&v);
    }

  The message shows the chain, `wrap<int> -> wrap<&int> -> wrap<&&int> ...`: the
  type that starts growing is near its START.

CORRECT (the recursive call passes the SAME type it was given):
    fn<T> count(x: T, n: int): int {
        if n <= 0 {
            return 0;
        }
        return 1 + count(x, n - 1);   // count<int> -> count<int>: one instantiation
    }

    fn main(): int {
        return count(5, 3) - 3;
    }

FIX:
  Make the recursive call pass a value of the generic's own type `T` (the same
  `x`, or another `T`) so the type stays fixed and only the VALUE changes. A type
  that is meant to grow with the depth is not something this compiler
  monomorphizes: stop it growing at some fixed, concrete depth.
