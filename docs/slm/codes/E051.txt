TURF E051 -- RESERVED CONSTRUCTOR NAME:

CAUSE:
  A method literally named `default` was hand-declared on a struct
  (`fn StructName.default(...): ...`). `default` is reserved: it's ALWAYS
  compiler-synthesized (recursively zero-initializes every field) and can
  never have user-written code attached to it, unlike `.new`, which is
  entirely user-defined.

CORRECT SYNTAX:
    struct Point {
        x: int,
        y: int
    }
    // 'Point::default()' already works with zero code written --
    // no declaration needed or allowed.

    fn Point.new(x: int, y: int): void {   // custom logic goes in .new
        self.x = x;
        self.y = y;
    }

INCORRECT:
    fn Point.default(): void {
        self.x = 0;
        self.y = 0;
    }
    // ERROR: 'default' is reserved and can't be declared by hand.

FIX:
  Remove the hand-written `.default` declaration entirely -- the compiler
  already generates a correct one for every struct automatically. If you
  need CUSTOM initialization logic (not just zeroing every field), define
  `.new` instead and call `StructName::new(...)`.
