TURF E115 -- INVALID OPERATOR DECLARATION:

CAUSE:
  An `operator` declaration has the wrong number of parameters for the symbol.
    - binary operators (`+ - * / % ** & | ^ << >> == != < > <= >=`): exactly two
    - `!` and `~`: unary, one parameter; `-` may be either unary or binary
    - `[]`: (self, index);  `[]=`: (self, index, value)
  The message states what the operator needs and how many were given.

INCORRECT:
    fn operator+(a: Vec, b: Vec, c: Vec): Vec { ... }     // `+` takes two
    fn operator[](self: Grid): int { ... }                // `[]` takes (self, index)
    fn operator[]=(self: Grid, i: int): void { ... }      // `[]=` takes three

CORRECT:
    fn operator+(a: Vec, b: Vec): Vec { ... }

FIX:
  Make the parameter list match the operator's arity.

RELATED: E080 (orphan rule), E028 (builtin-only operands), E097 (generic operators),
  E098 (write to a temporary).
