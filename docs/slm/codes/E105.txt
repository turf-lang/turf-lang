TURF E105 -- MISSING COMMA:

CAUSE:
  The parser was reading a list (struct fields, enum variants, call arguments, array
  items) and found a second item with no comma in front of it. The message usually
  says "`,` or the closing bracket", because it cannot tell whether a comma or the
  closing bracket is missing (see E104).

INCORRECT:
    struct Point {
        x: int
        y: int           // no comma after `x: int`
    }
    add(1 2)             // no comma between arguments

CORRECT:
    struct Point {
        x: int,
        y: int
    }
    add(1, 2)

FIX:
  Separate the items with commas (a trailing comma after the last item is fine), or
  add the closing bracket if the list was meant to end.

RELATED: E104 (unclosed delimiter), E102 (missing semicolon).
