TURF BUILTIN: lengthof()

SIGNATURE:
  int lengthof(string expr)

PURPOSE:
  Returns the number of bytes (characters) in a string.
  This calls the C standard library strlen() under the hood.

ARGUMENT COUNT:
  - Exactly 1 argument required.

ACCEPTED TYPES:
  - ONLY string. Passing int, double, or bool is a compile-time error.

RETURN TYPE:
  - int (always)

CORRECT USAGE:
  string msg = "hello"
  int n = lengthof(msg)           // n = 5
  int n2 = lengthof("world")      // n2 = 5
  int n3 = lengthof(input())      // valid: input() returns a string

INCORRECT USAGE:
  int n = lengthof(42)            // ERROR: argument is int, not string
  int n = lengthof(3.14)          // ERROR: argument is double, not string
  int n = lengthof(true)          // ERROR: argument is bool, not string

ARRAYS vs STRINGS:
  - For ARRAYS, use the .length property:    int n = arr.length
  - For STRINGS, use lengthof():             int n = lengthof(str)
  - DO NOT use lengthof() on arrays — it will be a type error.

COMMON MISTAKES:
- Calling lengthof on an array: use arr.length instead.
- Hallucinating len() or size() — these do not exist in Turf.
- Passing a non-string value.
