TURF BUILTIN: lengthof()

SIGNATURE:
  lengthof(expr: string): int

PURPOSE:
  Returns the number of characters in a string.

ARGUMENT COUNT:
  - Exactly 1 argument required.

ACCEPTED TYPES:
  - ONLY string. Passing int, double, or bool is a compile-time error.

RETURN TYPE:
  - int (always)

CORRECT USAGE:
  immut msg: string = "hello";
  immut n: int = lengthof(msg);        // n = 5
  immut n2: int = lengthof("world");   // n2 = 5
  immut n3: int = lengthof(io.input()); // valid: input() returns a string

INCORRECT USAGE & TYPE CASTING:
  // If you accidentally pass an int, double, or bool, cast it to a string
  // first with the postfix `to string` operator.
  immut n: int = lengthof(42);          // ERROR: argument is int, not string
  // FIX:
  immut n: int = lengthof(42 to string); // CORRECT

  immut n: int = lengthof(3.14);        // ERROR: argument is double, not string
  // FIX: lengthof(3.14 to string)

  immut n: int = lengthof(true);        // ERROR: argument is bool, not string
  // FIX: lengthof(true to string)

ARRAYS vs STRINGS:
  - For ARRAYS, use `.length()` (a method call):   arr.length()
  - For STRINGS, use lengthof():                   lengthof(str)
  - DO NOT use lengthof() on an array -- it is a type error.

COMMON MISTAKES:
- Calling lengthof() on an array: use arr.length() instead.
- Hallucinating len() or size() -- these do not exist in Turf.
- Passing a non-string value without casting it with `to string` first.
