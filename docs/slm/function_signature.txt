TURF FUNCTION DEFINITION AND RETURN TYPES:

DEFINITION SYNTAX:
  fn <return_type> <name>(<type> <param>, ...) { <body> }

  CORRECT EXAMPLES:
    fn int add(int a, int b) {
        return a + b
    }

    fn void greet(string name) {
        printline(name)
        return
    }

    fn double scale(double x, int factor) {
        return x * double(factor)
    }

    fn string label() {
        return "hello"
    }

RETURN RULES:
  - The function MUST have a return type: int, double, bool, string, or void.
  - `fn void` functions may use bare `return` with no value.
  - Non-void functions must return a value on ALL control paths.
  - The return value type must exactly match the declared return type,
    or an explicit cast must be used.

  INCORRECT:
    fn int foo() { }             // ERROR: missing return statement
    fn int bar() { return 3.14 } // ERROR: returning double from int function
  CORRECT FIX:
    fn int bar() { return int(3.14) }

PARAMETER RULES:
  - Parameters are declared as: <type> <name>
  - void is NOT allowed as a parameter type.
  - Supported parameter types: int, double, bool, string

VOID VALUE MISUSE:
  A void function call cannot be used in an expression or stored in a variable.

  INCORRECT:
    int x = voidFunc()           // ERROR: void value cannot be stored
    printline(voidFunc())        // ERROR: void value cannot be passed as argument
  CORRECT:
    voidFunc()                   // call it as a standalone statement

FORWARD CALLS:
  Turf performs a pre-pass that hoists function prototypes, so you CAN call
  a function before it is textually defined in the file.

COMMON MISTAKES:
- Missing return type between `fn` and the function name.
- Forgetting `return` in a non-void function.
- Returning wrong type without explicit cast.
- Using a void function call result as a value in an expression.
