TURF BUILTIN: typeof()

SIGNATURE:
  typeof(expression): string

PURPOSE:
  Returns the compile-time type name of an expression as a string.
  Resolved at compile time, not runtime.

ARGUMENT COUNT:
  - Exactly 1 argument is required. No more, no less.

ACCEPTED TYPES:
  - Any expression of any type: int, double, bool, string, a struct/enum
    instance, a pointer, an array.

RETURN TYPE:
  - string (always). Examples: "int", "double", "bool", "string", "Point"
    (a struct's own name), "Color" (an enum's own name).

CORRECT USAGE:
  io::printline(typeof(5));          // prints "int"
  io::printline(typeof(3.14));       // prints "double"
  io::printline(typeof("hello"));    // prints "string"
  io::printline(typeof(true));       // prints "bool"
  io::printline(typeof(my_point));    // prints "Point" (the struct's name)
  immut t: string = typeof(my_var);   // stores the type name

COMMON MISTAKES:
  typeof()          // ERROR: no argument provided (needs exactly 1)
  typeof(5, 10)      // ERROR: too many arguments (needs exactly 1)

HOW TO FIX:
  - Always pass exactly one argument to typeof().
  - If you want to check multiple expressions, call typeof() separately
    for each one.

SYNTAX RULES:
  - typeof must be followed by ( expression ).
  - The expression inside is evaluated for its TYPE only, not its runtime
    value -- it has no side effects even if the expression would normally
    have some.
  - typeof() with no arguments, or with more than one argument, is a
    compile-time error.
