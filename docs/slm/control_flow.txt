TURF CONTROL FLOW:

NOTE ON SEMICOLONS:
- Semicolons are optional in Turf-Lang. Both `x = 5` and `x = 5;` are valid.

IF STATEMENT - SINGLE-LINE (ternary form):
  Syntax: if <condition> then <expr> else <expr>
  The condition can optionally be wrapped in parentheses.

  CORRECT EXAMPLES:
    if x > 0 then x = 1 else x = 0
    if (x > 0) then x = 1 else x = 0    // parentheses around condition are optional

  RULES:
  - `then` keyword is mandatory in the single-line form.
  - `else` branch is mandatory in the single-line form.
  - `elseif` is NOT supported in the single-line form.

IF STATEMENT - BLOCK FORM:
  Syntax: if <condition> { <body> } elseif <condition> { <body> } else { <body> }
  The condition can optionally be wrapped in parentheses.

  CORRECT EXAMPLES:
    if x > 0 {
        printline(x)
    } elseif x < 0 {
        printline(-x)
    } else {
        printline(0)
    }

    if (score >= 90) {    // parentheses around condition are optional
        printline("A")
    }

  RULES:
  - `elseif` is one keyword (no space). `else if` (with space) is a parse error.
  - `else` branch is optional in block form.
  - `then` keyword must NOT be used in block form; use `{` instead.

WHILE LOOP:
  Syntax: while <condition> { <body> }

  CORRECT EXAMPLES:
    while x < 10 {
        x++
    }

    while (running) {    // parentheses around condition are optional
        x += 1
    }

BREAK AND CONTINUE:
  - `break` exits the innermost loop immediately.
  - `continue` skips to the step/condition of the innermost loop.
  - Both are parse errors if used outside a loop body.

  CORRECT EXAMPLES:
    while true {
        if x > 5 { break }
        x++
    }

FOR LOOP:
  Syntax: for <var> in <start> .. <end> step <step_expr> { <body> }

  IMPORTANT: The `step` clause is an arbitrary ASSIGNMENT EXPRESSION executed
  after each iteration. It is NOT a numeric increment value.
  The loop variable `<var>` is automatically declared as int or double
  based on the type of <start>.

  The `step_expr` is evaluated after the body on every iteration.
  It should mutate the loop variable (e.g. i += 1, i *= 2).

  CORRECT EXAMPLES:
    for i in 0 .. 10 step i += 1 {
        printline(i)
    }

    for i in 10 .. 0 step i -= 1 {
        printline(i)
    }

    int factor = 2
    for i in 1 .. 100 step i *= factor {
        printline(i)
    }

  INCORRECT EXAMPLES:
    for i in 0 .. 10 step 1 { ... }      // ERROR: step must be an expression that modifies i
    for i in 0 to 10 step i += 1 { ... } // ERROR: use '..' not 'to'
    for (int i = 0; i < 10; i++) { }     // ERROR: C-style for loops do not exist in Turf
    for i in 0..10 { ... }               // ERROR: 'step' clause is required

COMMON MISTAKES:
- Using `else if` (with space) instead of `elseif`.
- Using `then` in block form (only valid in single-line form).
- Forgetting the `step` clause in a `for` loop.
- Using `step 1` (a literal) instead of an assignment expression like `i += 1`.
- Using `do { } while` or C-style `for(;;)` — these do not exist in Turf.
