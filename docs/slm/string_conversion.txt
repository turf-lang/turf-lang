TURF STRING CONVERSION:

TYPE CASTING SYNTAX (postfix `expr to Type`, NOT `Type(expr)`):
  value to string    // convert to string
  value to int       // convert to int
  value to double    // convert to double

SUPPORTED CONVERSIONS TO STRING:
  42 to string      // int to string    -> "42"
  3.14 to string    // double to string -> "3.14"
  true to string    // bool to string   -> "true" or "false"
  // string to string is a no-op

SUPPORTED CONVERSIONS FROM STRING:
  "42" to int       // string to int    -- parsed at runtime
  "3.14" to double  // string to double -- parsed at runtime
  // The WHOLE string must be the number: "12abc", " 12", "+5", "1.5" to int
  // all panic at runtime. A literal that can never convert ("abc" to int) is
  // E149 at compile time. For user input, prefer strings::parse_int /
  // strings::parse_double, which return an error to recover from.

WHAT IS NOT SUPPORTED:
  some_string + 5
    // ERROR: "Cannot apply operator '+' to types 'string' and 'int'."
    //        Fix: some_string + (5 to string)
  some_array to string
    // ERROR: arrays cannot be converted to strings this way.

STRING CONCATENATION:
  Two strings CAN be combined with '+' directly:
    immut greeting: string = "hello " + "world";   // "hello world"
  A string and a non-string CANNOT be combined with '+' -- convert the
  non-string side with `to string` first.

STRING LENGTH VS ARRAY LENGTH:
  - strings::length(str) gets the character count of a STRING. It accepts
    ONLY strings -- not int, double, bool, or arrays.
  - For an array, use `.length()` (a method call) instead, not
    strings::length().

PRINT AND PRINTLINE:
  Both accept int, double, bool, or string directly -- no separate
  toString()-style call is needed for a SINGLE value:
    io::printline(42);         // prints "42"
    io::printline(3.14);       // prints "3.14"
  To combine a label and a value in one call, cast the value to string
  and concatenate:
    io::printline("Score: " + (42 to string));

CORRECT EXAMPLES:
  immut s: string = 100 to string;    // "100"
  mut n: int = "99" to int;           // 99
  immut len: int = strings::length("hello"); // 5

COMMON MISTAKES:
- Trying to concatenate a string and a NUMBER with '+' without casting the
  number to string first (string + string works fine on its own).
- Using single quotes '' instead of double quotes "" for string literals
  (single quotes are a syntax error).
- Using a `Type(expr)` function-call-style cast, or `toString()`/`str()` --
  none of these exist; the only cast syntax is postfix `expr to Type`.
