TURF SYNTAX ERROR:

NOTE ON SEMICOLONS:
  Semicolons are OPTIONAL in Turf-Lang. Do not add or remove them as a fix.

COMMON SYNTAX ERRORS:

1. UNKNOWN TOKEN / UNEXPECTED EXPRESSION:
   Occurs when the parser sees a token it cannot handle as the start of
   an expression. Often caused by a misspelled keyword or unsupported operator.

   INCORRECT:
     !! x                        // ERROR: logical NOT (!) is not implemented
     x and y                     // ERROR: use && not 'and'
     x or y                      // ERROR: use || not 'or'
     x & y                       // ERROR: bitwise & does not exist — use &&
     x | y                       // ERROR: bitwise | does not exist — use ||
     x ** 2                      // ERROR: use ^ for exponentiation

2. MISSING EXPECTED TOKEN:
   Occurs when the parser expects a specific token but finds something else.

   INCORRECT (block-form if):
     if x > 0 then { ... }       // ERROR: block form uses { } directly, not 'then'
     if x > 0 { } elif { }       // ERROR: use 'elseif', not 'elif'

   INCORRECT (function call):
     print x                     // ERROR: must use parentheses: print(x)
     printline x                 // ERROR: must use parentheses: printline(x)

3. KEYWORD TYPO:
   The compiler detects near-matches to keywords and reports them.

   Examples of typos detected:
     whlie, fro, retrun, breka, cotninue, els, elsief

4. UNTERMINATED STRING:
   Occurs when a string is opened with " but not closed.

   INCORRECT:
     string s = "hello           // ERROR: missing closing "

   CORRECT:
     string s = "hello"

5. VOID AS VARIABLE TYPE:
   `void` can ONLY be used as a function return type, NOT as a variable type.

   INCORRECT:
     void x = something()        // ERROR: void is not a variable type

SUPPORTED OPERATORS (reference):
  Arithmetic: + - * / % ^
  Relational: == != < > <= >=
  Logical:    && ||
  Assign:     = += -= *= /= %=
  Increment:  x++ x-- ++x --x

UNSUPPORTED (do not suggest):
  ! (NOT), & | ^ (bitwise), ** (power, use ^)
