TURF-LANG GENERAL REFERENCE
============================

NOTE ON SEMICOLONS:
  Semicolons are OPTIONAL in Turf-Lang. Both `x = 5` and `x = 5;` are valid.

---

TYPES:
  int      64-bit signed integer
  double   64-bit floating point (alias: float)
  bool     boolean: true or false
  string   byte string pointer
  void     ONLY allowed as a function return type, never as a variable type

---

LITERALS:
  42          integer
  3.14        double
  true        bool
  false       bool
  "hello\n"   string (escape sequences: \n \t \\ \")

---

VARIABLES:
  Declared with type keyword and must be initialized immediately.
  type name = value

  int x = 5
  double pi = 3.14
  bool flag = false
  string msg = "hi"

  REASSIGNMENT (no type keyword):
    x = 10
    x += 5
    x -= 2
    x *= 3
    x /= 2
    x %= 4
    x++
    x--
    ++x
    --x

---

ARRAYS:
  type[SIZE] name
  type[SIZE] name = [v1, v2, v3]

  int[5] nums
  int[3] primes = [2, 3, 5]

  ACCESS:
    primes[0]               // read element (zero-indexed)
    primes[0] = 7           // write element

  LENGTH:
    int n = primes.length   // .length property — NOT a function call

  RULES:
  - SIZE must be a positive integer literal.
  - Compound assignment on elements (arr[0] += 1) is NOT supported.
    Use arr[0] = arr[0] + 1 instead.

---

OPERATORS:
  Arithmetic:  +  -  *  /  %  ^
  Relational:  ==  !=  <  >  <=  >=
  Logical:     &&  ||
  Unary:       - (negate)
  Assignment:  =  +=  -=  *=  /=  %=
  Increment:   x++  x--  ++x  --x

  NOT SUPPORTED:
    !  (logical NOT — use == false instead)
    &  |  (bitwise operators do not exist)
    ** (use ^ for exponentiation)

  TYPE PROMOTION IN EXPRESSIONS:
    bool -> int -> double (promoted automatically in expressions)
    string cannot be combined with any other type in arithmetic

---

TYPE CASTING (explicit):
  int(expr)       double/string -> int
  double(expr)    int/string -> double
  string(expr)    int/double/bool -> string

  EXAMPLES:
    int(3.14)       // 3
    double(10)      // 10.0
    string(42)      // "42"
    string(true)    // "true"
    int("99")       // 99 (runtime parse of string)

---

CONTROL FLOW:

  IF (single-line form):
    if <cond> then <expr> else <expr>
    if (x > 0) then x = 1 else x = 0   // parentheses optional

  IF (block form):
    if <cond> {
        ...
    } elseif <cond> {
        ...
    } else {
        ...
    }
    // Parentheses around condition are optional in both forms.
    // `elseif` is one word — `else if` is a parse error.
    // `then` must NOT be used in block form.

  WHILE LOOP:
    while <cond> {
        ...
    }

  FOR LOOP:
    for <var> in <start> .. <end> step <step_expr> {
        ...
    }
    // <step_expr> is an ASSIGNMENT EXPRESSION executed after each iteration.
    // The loop variable is automatically declared (int or double).
    EXAMPLE:
      for i in 0 .. 10 step i += 1 { printline(i) }
      for i in 10 .. 0 step i -= 2 { printline(i) }

  BREAK / CONTINUE:
    break     // exits innermost loop
    continue  // skips to the step expression of innermost loop

---

FUNCTIONS:
  fn <return_type> <name>(<type> <param>, ...) {
      return <value>
  }

  fn int add(int a, int b) {
      return a + b
  }

  fn void greet(string name) {
      printline(name)
      return
  }

  RULES:
  - Return type is required (int, double, bool, string, void).
  - Non-void functions must return a value on every code path.
  - void functions use bare `return` or can omit it.
  - Parameters use `type name` pairs; void is not a valid parameter type.
  - Functions can be called before they are defined (pre-pass hoisting).

---

BUILTIN FUNCTIONS:

  print(expr)
    Prints expr to stdout with no newline.
    Accepts: int, double, bool, string

  printline(expr)
    Prints expr to stdout followed by a newline.
    Accepts: int, double, bool, string

  input()
    Reads a line from stdin. Returns: string

  lengthof(str)
    Returns the number of characters in a string. Returns: int
    Accepts: string ONLY. For arrays, use arr.length instead.

  typeof(expr)
    Returns the compile-time type name as a string.
    Returns: "int", "double", "bool", "string", "void", or "unknown"

---

COMMON PITFALLS:
- Using `else if` (space) instead of `elseif` (one keyword).
- Using C-style for loops: for(int i=0;...) does not exist in Turf.
- Forgetting `step <expr>` in a for loop (step is required).
- Using step as a numeric value (step 1) — it must be an expression (i += 1).
- Using compound assignments on array elements (arr[0] += x is not supported).
- Calling lengthof() on an array instead of using .length.
- Mixing string and numeric types in arithmetic without explicit cast.
- Using ! for logical NOT — use == false instead.
