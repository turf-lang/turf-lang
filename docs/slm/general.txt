TURF LANGUAGE REFERENCE (condensed):

TYPES: int, double, bool, string
DECLARATIONS: int x = 5 | double pi = 3.14 | bool flag = true | string s = "hi"
TYPE CASTING: int("42") | double(10) | string(x)
TYPE RULES: Implicit promotion bool->int->double in expressions only. No implicit cast in assignments.
OPERATORS: + - * / % ^ | += -= *= /= %= | ++ -- | && || | < > == != <= >=
CONTROL FLOW: if/else/elseif | while { } | break | continue
IF EXPRESSION: int max = if a > b then a else b
FUNCTIONS: fn name(type param) -> type { return val }
ARRAYS: int arr[5] = {1,2,3,4,5}
BUILTINS: print(), printline(), input(), typeof(), lengthof(), string(), int(), double()
STRINGS: support \n \t \\ \" escape sequences

COMMON MISTAKES:
- Assigning double to int without explicit cast: use int(x)
- Using undeclared variables
- Function return type mismatches
- Mixing string concatenation with non-string types without string()
- Using C-style for loops (Turf uses: for i in 0..n step 1 { })
- break/continue outside a loop
- Missing return in non-void functions
- Array index out of bounds
- Declaring the same variable twice in one scope

COMMON ANTI-PATTERNS (DO NOT USE):
- 'println': Not in Turf. Use 'printline' for newlines.
- 'printf': Not in Turf. Use 'print' for formatted output.
- 'var' or 'let': Not in Turf. Always use explicit types: 'int x = 5'.
- 'for (int i=0; i<n; i++)': C-style loops are not supported.
