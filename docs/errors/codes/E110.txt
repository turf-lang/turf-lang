A specific word or symbol was expected

Turf was in the middle of a construct that has a fixed shape and found something other than the next fixed piece. The message names the exact word or symbol it wanted.

A few of the fixed shapes:

    for i in 0..10 { ... }               // `in` after the loop variable
    do { ... } while keep_going;          // `while` after a do-block
    give a otherwise b                   // `otherwise` after `give`
    compare x { matches 1: ... }         // `matches` or `otherwise` in a compare
    value recover run { ... };           // `run`, `produce` or `as` after `recover`
    extern fn malloc(n: int): ptr;       // `fn` after `extern`
    export immut MAX: int = 3;           // `immut` after `export`
    machine Door { Open -> Closed }      // `->` between two states

Compare what you wrote with the shape above and add or fix the piece the message asks for. If you wrote a lookalike (a `then` instead of `{`, `:=` instead of `=`), that is the one to change: Turf has no alias for it.

One shape is a generic function's type arguments written without `::`. `identity<int>(3)` reads as `identity < int ...`, and `int` cannot be compared, so this is E110. Type arguments of a generic function follow `::`, and the compiler prints the fix:

    immut a: int = identity<int>(3);      // E110
    immut a: int = identity::<int>(3);    // fine
