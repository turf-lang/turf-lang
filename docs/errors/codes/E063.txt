E063 is retired -- a bad argument to power() is now reported as E056 or E025

Older versions of Turf treated `power` as a compiler built-in with an error of its own. It is an ordinary function in the standard library now (`math::power`), like every other, so nothing produces E063 any more. The number is kept so that an old log or tutorial that mentions it still has somewhere to land, and is never reused for anything else.

Passing `power` something that isn't a number is reported like any other call with the wrong argument types:

    mut bad: int = math::power(true, 2);

That gives `E025`: Turf found `math::power`, and none of its versions take a `bool`. `power` is defined for numbers -- an `int` or a `double` for each of the base and the exponent:

    mut a: int = math::power(2, 10);          // 1024
    mut b: double = math::power(2.0, 0.5);    // the square root of 2

Run `turf --explain E025` for the full explanation.
