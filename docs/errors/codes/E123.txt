An array's size has to be a positive whole number

An array is declared with a fixed size written in square brackets, and that size is a count of slots, so it must be a whole number greater than zero:

    mut numbers: int[5];             // five slots

These are rejected:

    mut empty: int[0];               // an array with no slots can hold nothing
    mut negative: int[-3];           // you can't have -3 slots
    mut half: int[2.5];              // slots come in whole numbers

If you don't know how many items you will need in advance, an array is the wrong tool: `List<T>` (from `import list;`) grows as you add to it.
