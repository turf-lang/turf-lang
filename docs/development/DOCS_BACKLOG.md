# Documentation backlog

Documentation that a landed change still needs. The rule (`docs/planning/ROADMAP_v3.0.0.md`
§4.4): a change documents itself in the same pull request; anything it cannot
document there gets a row here at once. A row is deleted when the page is
written; git keeps the history.

A minor `2.N.0` is not tagged while a row targets `2.N`. Rows for other
repositories (`turf-cli`, `turf-lsp`, `turf-fuzz`, `website`) live here too, so
there is one list to check before a release.
