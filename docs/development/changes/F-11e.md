# F-11e — the compiler's own function-shaped tests are `@test` functions (issue #354)

TDP-2-006's last item. A `fail_*.tr` whose expected error lies inside `main`'s
body, or whose program panics, is now a `@test(compile_error, Exxx, "text")` or
`@test(panic, "text")` function holding that body, several to a file per
directory (`rejected_in_functions*.tr`, `panics_in_functions*.tr`), or alone as
`<topic>_rejected.tr` / `<topic>_panics.tr`. The test name is the old file name
with `rejects_`/`panics_` for `fail_`.

What moved: 362 files (295 rejected, 67 panics), into 50 merged files and
single files. A file moved only when

- it pins one code and at most one message text (an `@test` outcome holds one
  of each), and no `EXPECT-FIX`, `EXPECT-NO-DIAG`, `EXPECT-EXIT` or `LINT:`;
- the original compile reports that code on a line inside `main`'s body (238
  were left: the error is at a declaration, or the code is reported elsewhere);
- the converted test passes on its own, and a merged file passes as a whole
  (merges with a top-level name in common were not made);
- no tool compiles it by name: the DX-10 snapshot INDEX, the `--smart`
  benchmark corpus, a workflow or a smoke script (78 files);
- the whole program is not compiled for a reason of its own:
  `fail_server_routes_private.tr` is compiled through Codegen at `-g`
  (REL-004), which a `compile_error` test never is.

What stays a `fail_*` file: syntax errors, errors at a declaration, exit
statuses, fixes, `EXPECT-NO-DIAG`, hints, flow-analysis errors (a
`compile_error` test is not flow-analysed), and the files above.

Expectations counted before and after (code, text, runtime text, fix, exit,
and each `@test` outcome's code and text): 1797 before, 1828 after; 890
`fail_*` files before, 527 after. `tests/CONFORMANCE.md` and
`tests/CONFORMANCE_ITEMS.md` name moved tests as `path.tr: test_name`, which
`scripts/check/conformance_check.py` accepts as negative evidence; docs and
comments that named a moved file point at its new home.
`tests/DIAGNOSTIC_GAPS.txt` named none of them, and `tests/compat/2.0/` is
unchanged.
