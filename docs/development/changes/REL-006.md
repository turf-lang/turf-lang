## Why
`ROADMAP_v2.0.0.md` REL-006: rewrite `docs/reference/**` against the frozen 2.0
compiler, add `memory_and_safety.md` and `docs/MIGRATING_TO_2.md`, rewrite the
README, and audit `docs/architecture/**` against the code. Completion: the
reference examples check is green, `PENDING.md` has no reference rows, and the
migration guide covers every Part V row.

## Language semantics
None changed. The compiler was frozen for the whole pass: no file under `src/`,
`include/`, `runtime/`, `lib/std/` or `tests/` was edited. Behaviour that looked
wrong was recorded, not fixed (see *Unresolved questions*).

## Compiler architecture
None. `docs/architecture/**` was corrected to match the code; the largest
corrections: parser recovery is a C++ exception (`RecoverUnwind`), not
`setjmp`; pre-pass errors are reported, not discarded; the Monomorphizer runs
between the type checker and struct codegen; the runtime's init, collector,
Windows fault handler and type bitmaps all exist and are used (the old
`runtime.md` said otherwise); `boundary.md`'s one documented exception no
longer exists.

## Runtime changes
None.

## Standard-library changes
None. Every `pub` item is now documented on its page, checked against
`stdlib_surface_check.sh --list`.

## New invariants
None.

## Removed assumptions
- The reference was "grounded in the 1.0 compiler": every page was rewritten,
  not patched. Claims carried over from 1.0 were re-checked by compiling; dozens
  were wrong (type erasure, string keys compared by identity, zero-filled
  variables, error codes that had changed).
- User-facing docs no longer carry milestone IDs, dates of changes or compiler
  internals.

## Tests
`scripts/check/doc_examples.py`: 356 blocks, 347 compile or fail with their
marked code, 9 skipped (multi-file or needing a flag/library; each was checked
by hand). `docs/reference/DOC_EXAMPLES_GAPS.txt` went from 133 entries to 0.
`slm_doc_examples_check.sh` green after the E084 edit. README and the migration
guide are outside the checker; their blocks were extracted and compiled.

## Known pitfalls
- A `TURF_HOME` pointing at a directory that does not exist makes every compile
  fail with E027 (the owner's shell exported one). Run the checks with
  `env -u TURF_HOME`.
- Seventeen parallel agents exhausted the usage limit and all died mid-task;
  two at a time worked.

## Handbook impact
The `docs/`, README and migration rows of `PENDING.md` (77) moved to `DONE.md`.
23 rows remain: the handbook's own chapters, and one code change for the SLM's
construct-doc routing (`src/diagnostics/ErrorCategory.h`), deferred with the
compiler fixes below. The handbook was restructured for a compiler-design
course (`turf-handbook/STYLE.md`) and then paused.

## Unresolved questions
Writing the docs found about fifty compiler and stdlib issues: crashes on
specific inputs (a `!void` call as an `if` condition, `==` on two collections,
unary `-` on `int32`, a method chained on a call returning a `List`, ...),
accepted invalid programs (non-`bool` conditions, non-numeric range bounds),
a safe-code gap (string byte writes are bounds-checked below zero only), and
smaller diagnostics and stdlib defects. They are kept in a local working list
and are fixed together, each with a regression test, after this milestone.
Two need an owner decision first: whether `int` truthiness is part of the
language, and whether FREEZE §6.1's "unsupported operations on `T` are
instantiation-site errors" or the compiler's earlier rejection is the rule.
